# Air Supply

CS7470 Group 28 — upload a Phyphox barometer CSV to see ventilation score and pressure chart.

## Run the UI

Open `web/index.html` in your browser, or:

```bash
cd web
python3 -m http.server 8000
```

Then go to `http://localhost:8000` and upload a CSV exported from Phyphox (**Export data → Raw Data**).
